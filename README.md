# Everything Everywhere Daily — connected listening paths

An independent fan catalogue of 255 connected listening paths from Gary Arndt's Everything Everywhere Daily.

Open the GitHub Pages site to search paths, follow ordered episodes, and inspect explicit/inferred connections with brief source excerpts. Episode links point to Spotify; source links point to the publisher.

The catalogue uses a frozen November 2026 analysis of available publisher scripts. Names and ordering are editorial drafts; publisher scripts can differ from recordings. This is a selected graph, not an exhaustive mapping.

Credit: [Gary Arndt / Everything Everywhere Daily](https://everything-everywhere.com/everything-everywhere-daily-podcast/). Quoted publisher text belongs to its original author. This export includes brief evidence excerpts, not full transcripts.

This folder is a self-contained static website. It requires no service credentials or backend. The preparation and authenticated publishing tools stay outside this public folder.
